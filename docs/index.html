What is Horus

Hand it anything — it figures out what to do

No flags to memorize. horus <thing> auto-detects what you gave it and runs the right analysis.

a file path
Hashes it (MD5/SHA-1/SHA-256), parses the PE, scores risk, pivots on embedded indicators
a hash
Queries VirusTotal and reports engine detections — MD5, SHA-1 or SHA-256 auto-detected
an IP address
Queries VirusTotal and AbuseIPDB in parallel for reputation & abuse reports
a domain / URL
Queries VirusTotal, reports category, reputation and per-engine verdicts
an email
Queries VirusTotal for associated reputation
Under the hood

Real static analysis, not just a hash lookup

🧮

Hashing

MD5, SHA-1 and SHA-256 computed via Windows BCrypt/CNG — plus a Mandiant-compatible imphash for family pivoting.

🧷

PE parser

PE32 / PE32+ headers, sections and imports — every offset and length bounds-checked, so malformed samples are safe to feed it.

🌡️

Entropy & packing

Per-section Shannon entropy flags packed/encrypted regions and known packers (UPX, Themida, VMProtect…).

🧠

Capability scoring

~110 Windows APIs mapped to the capabilities they imply — injection, keylogging, persistence, evasion — and the dangerous combinations.

🛰️

Intel enrichment

VirusTotal v3 + AbuseIPDB v2 over Windows WinHTTP, fanned out in parallel. Extensible IntelSource interface.

🧩

JSON + exit codes

--json for SIEM/automation; exit code 1 when a target is suspicious or malicious, so it drops straight into pipelines.

The scoring engine

It interprets imports — it doesn't just list them

Common dual-use APIs (LoadLibrary, CreateProcess) are shown but don't move the score alone. Only rare primitives and dangerous combinations do.

Safety & limitations

Read-only by design

It never runs the sample. Horus only reads bytes — it never executes, modifies, or generates anything.
Malformed samples are safe. The PE parser bounds-checks every offset and length before reading.
A triage aid, not a final verdict. Pair the static score with VirusTotal consensus and, for anything that matters, a sandbox detonation.
Static analysis has limits. Heavily obfuscated samples that resolve imports at runtime score low — that's expected; entropy heuristics only partly compensate.
